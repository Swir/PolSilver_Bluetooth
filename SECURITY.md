# Security and responsible use

PolSilver Bluetooth is a local diagnostics utility. Use it only with Bluetooth devices you own, administer, or have explicit authorization to inspect.

Version 2 limits functionality to bounded discovery, read-only local adapter diagnostics, exported scan metadata and user-confirmed GATT inspection. It does not automate credential bypass, MITM interception, destructive adapter changes or public/large-scale scanning.

## Reporting a vulnerability

Please avoid posting secrets, device identifiers or sensitive captures in a public issue. Describe the affected component and reproduction steps with sanitized data.
